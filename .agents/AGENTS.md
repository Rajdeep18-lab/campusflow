# Project Rules & Workflow Guidelines

- **Git Auto Sync**: After making any code changes in this project, automatically stage, commit all modified/new files with a meaningful commit message, and push to `origin main`.
- **Deployment Platform**: The primary deployment target is Vercel. Keep `base: '/'` in `vite.config.js` and keep `vercel.json` configured for SPA routing.
- **Git Remote**: Do not modify the Git remote configuration (`origin https://github.com/Rajdeep18-lab/campusflow.git`).
